# Assets / 图标资源

## `logo.png`

The official MiniMax square logo, used here to identify the upstream service
this plugin connects to. The PNG is copied without modification from the
logo URL declared by the [official MiniMax website](https://www.minimax.io/)
in its `Organization.logo` and `Brand.logo` structured data.

- Official asset: <https://filecdn.minimax.chat/public/58eca777-e31f-448a-9823-e2220e49b426.png>
- Retrieved: 2026-10-28
- Format: PNG, 300 × 300 pixels; original colors and dimensions retained.
- Plugin store URL: <https://raw.githubusercontent.com/dillonzq/cpa-minimax/main/assets/logo.png>

To refresh the local copy from the same official source:

```sh
curl --fail --location \
  https://filecdn.minimax.chat/public/58eca777-e31f-448a-9823-e2220e49b426.png \
  --output assets/logo.png
```

此文件为 MiniMax 官网在 `Organization.logo` 和 `Brand.logo` 结构化数据中声明的
官方方形 Logo，原样保存，保留原始尺寸及配色。以上链接记录了官方来源及插件商店地址。
