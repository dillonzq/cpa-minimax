# Security policy

[README](README.md) · [Contributing](CONTRIBUTING.md)

## Supported versions

Only the latest release receives security updates. Include the exact plugin version or commit in a report, including for development builds.

## Report a vulnerability

Use GitHub’s private vulnerability reporting from this repository’s **Security → Report a vulnerability** page. Do not post exploitable details in public issues or pull requests.

Include:

- The affected behavior and potential impact.
- Reproduction steps or a minimal sanitized payload.
- The CLIProxyAPI version, plugin version/commit, operating system, and architecture.
- Relevant configuration and logs with credentials, management tokens, and personal data removed.

We will acknowledge reports within 48 hours, investigate the issue, and coordinate a fix and disclosure before publishing details.

For non-security bugs, use the [issue templates](https://github.com/dillonzq/cpa-minimax/issues/new/choose).
